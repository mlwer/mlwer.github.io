# 인스타그램 향수 계정(@my_scent.lab) 캔바 작업 규칙

이 문서는 Claude가 캔바(Canva)에서 인스타그램 카드뉴스/릴스 콘텐츠를 작업할 때
반복적으로 따라야 하는 규칙을 정리한 메모입니다.

## 1. 폴더 정리 규칙

- 텍스트/이미지 수정을 **commit(저장)까지 완료한** 디자인은 별도 요청 없이
  자동으로 **인스타 > 작업** 폴더로 이동한다.
  - 인스타 폴더 id: `FAHWEe4iY6Q`
  - 작업 폴더 id: `FAHWEaXRMjM`
- 아직 확정되지 않은 초안(편집 트랜잭션 진행 중)은 이동하지 않는다.
- 향수 외 다른 주제로 폴더를 분리하고 싶다는 요청이 있으면 그때 지정된 폴더로 이동한다.

- **생성형 AI로 만든 이미지도 주제별 폴더에 정리**한다.
  - 이미지 상위 폴더: **인스타 > 이미지** (id: `FAHWHgBB_fU`)
  - 그 아래에 작업 주제 이름으로 하위 폴더를 만들어(예: "계절별 향수 뿌리는 법",
    id: `FAHWHsnQ5GY`) 해당 디자인을 위해 생성한 배경/인서트 이미지를 전부 모아둔다.
  - 새 주제로 이미지를 생성할 때마다 `create-folder`로 `인스타 > 이미지` 아래에
    주제별 폴더를 새로 만들고, 생성한 이미지(media id)들을 전부 그 폴더로
    `move-item-to-folder` 한다.

## 2. 새 카드뉴스 제작 규칙

새로운 카드뉴스를 만들 때는 **인스타 > 샘플** 폴더(id: `FAHWEef2pzI`)에 있는
기존 샘플 디자인을 베이스로 복제해서 시작한다.

- 참고 샘플
  - 카드뉴스 샘플: "향수 카드뉴스 01 - 첫 향수 고르기" (`DAHWA-euqYk`)
  - 릴스 샘플: "향수 릴스 01 - 첫 향수 고르기" (`DAHWEGPbypQ`)
  - 카드뉴스 샘플(에디토리얼 포토 스타일): "향수 카드뉴스 02 - 에디토리얼 포토 템플릿 (계절별 레이어링)"
    (`DAHWLJdsFU8`) — 베이지 배경 + TIP 01/02/03 라벨 + 사진/텍스트 분할 레이아웃 +
    브릿지 슬라이드 + 흰 카드 CTA 구조. Mirra AI가 만든 카드뉴스 느낌을 참고해서
    제작. 다크 풀블리드 톤의 01번 샘플과는 결이 달라서, 주제에 더 잘 맞는 쪽을
    골라 복제하면 된다.
- 제작한 예시: "향수 카드뉴스 04 - 계절별 향수 뿌리는 법" (`DAHWEcQ65uk`)

### 지켜야 할 것

1. **배경 이미지는 생성형 AI로 새로 제작**한다.
   - 스톡 사진을 그대로 재사용하지 않고, 각 페이지 주제에 맞는 프롬프트로
     `generate-image`를 사용해 새 이미지를 생성해서 교체한다.
   - 배경뿐 아니라 페이지 안의 인서트(소형 합성) 이미지도 동일하게 생성형 AI로
     교체해서 톤을 통일한다.
2. **폰트와 글자 크기는 건드리지 않는다.**
   - 샘플 디자인에 설정된 `fontRef`, `fontSize`, `fontWeight` 등 서식 값은
     그대로 유지한다.
   - `replace_text` / `find_and_replace_text`처럼 텍스트 내용만 바꾸는 조작만
     사용하고, `format_text`로 폰트나 크기를 변경하지 않는다.
3. **바뀌는 것은 글 내용(카피)뿐**이다.
   - 레이아웃(요소 위치·크기), 페이지 수, 구성 순서는 샘플과 동일하게 유지한다.
   - 배경/인서트 이미지와 텍스트 카피만 새 주제에 맞게 교체한다.
4. **새 도형(`insert_shape`)에는 나중에 `update_fill`로 이미지를 채울 수 없다.**
   - 샘플 안에 원래부터 있던 이미지 인서트(둥근 모서리 사진 박스 등)는
     `update_fill`로 교체 가능하지만, 이번 작업 중 새로 `insert_shape`로 만든
     도형은 `isMediaReplaceable: false`로 생성되어 이미지 채우기가 실패한다.
   - 새 레이아웃에서 사진 박스가 필요하면 `insert_fill`로 이미지 요소를 직접
     넣는다 (단, 모서리 둥글게 처리는 안 됨 — 각진 사각형이 됨).
   - 원형 아이콘처럼 색만 있는 도형(저장/팔로우 버튼 등)은 `insert_shape` +
     `color`로 문제없이 만들 수 있다.

## 3. 작업 순서 요약

1. 샘플 폴더의 카드뉴스(또는 릴스) 디자인을 `copy-design`으로 복제
2. 복제본에서 페이지별 텍스트를 새 주제 카피로 `replace_text` / `find_and_replace_text`
3. 페이지별 배경 및 인서트 이미지를 `generate-image`로 새로 생성 후 `update_fill`로 교체
4. 모든 변경을 `commit`으로 저장
5. 완성된 디자인을 인스타 > 작업 폴더(`FAHWEaXRMjM`)로 `move-item-to-folder`
6. 이번 작업에서 생성한 이미지들을 인스타 > 이미지 > (주제별 폴더)로 `move-item-to-folder`
